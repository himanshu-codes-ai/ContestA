# CF Analyzer

CF Analyzer is a competitive-programming analytics app for Codeforces users. It combines a React frontend, an Express backend, and generated architecture context from the `graphify-out/` directory to help users inspect performance, identify weak topics, compare profiles, and plan upsolving work.

## What this project does

- Analyze a Codeforces handle and surface rating, submissions, contest activity, and trend summaries.
- Show topic-level weakness analysis and personalized problem recommendations.
- Track upsolving progress with a two-tier workflow: triage and challenge.
- Visualize daily activity with a heatmap and compare two users side by side.
- Provide authentication/profile pages alongside the main analytics views.

## Project structure

- `client/` — Vite + React frontend
  - `src/pages/` — dashboard, search, recommendations, heatmap, compare, login, profile
  - `src/services/` — queued API client for backend calls
  - `src/context/` — auth and user-state context
- `server/` — Express API layer
  - `routes/api.js` — backend endpoints for user data, recommendations, daily problems, and upsolving
  - `services/` — Codeforces integration and recommendation logic
- `graphify-out/` — generated project graph artifacts
  - `GRAPH_REPORT.md` — summary of the codebase structure and key abstractions
  - `graph.html`, `graph.json` — interactive graph exploration assets

## Key features

- Codeforces profile diagnostics and rating history
- Topic analysis and weakness detection
- Recommendation engine for next problems to solve
- Daily problem generation and history tracking
- Submission heatmap and comparison tools
- Optional auth/profile flow using Supabase/Firebase-style integrations

## Tech stack

- Frontend: React, Vite, React Router, Recharts, React Calendar Heatmap
- Backend: Node.js, Express, Axios, express-rate-limit, node-cache
- External data: Codeforces API
- Architecture context: generated by `graphify-out/`

## Getting started

### 1. Install dependencies

```bash
cd client
npm install

cd ../server
npm install
```

### 2. Start the backend

```bash
cd server
npm run dev
```

### 3. Start the frontend

```bash
cd client
npm run dev
```

The frontend is typically available at `http://localhost:5173` and the backend at `http://localhost:5000`.
